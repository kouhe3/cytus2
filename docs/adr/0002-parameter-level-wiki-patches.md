# 已有 wiki 页面只做参数级补丁

对 BiliGame 上已存在的页面，导出器只生成模板参数块（按参数名替换），不生成整页；只有页面不存在时才生成完整页。原因是站内页面已经有人工维护的轶事、歌词、曲绘与历史命名变体，整页覆盖会不可逆地丢内容；参数级补丁也正好对应「产出 wikitext 参数对」这条验收标准。

## 考虑过的方案

- **整页覆盖**：实现最简单，但会抹掉人工内容，且历史页标题变体（`IM：标题`、`(公告)标题`）会被统一成一种，不可接受。
- **只建新页**：不会破坏现有内容，但绝大多数歌曲页永远拿不到我们的数据。

## 后果

- 导出器必须能解析现有 wikitext 的参数块，并保留不认识的参数与嵌套模板。
- 补丁的应用需要人工或 bot 按参数替换，不能整页 copy。
- 页面标题必须先匹配站内已有标题（见 Q30），匹配不到才新建。
